# Resume a project

**Use when** returning to a project after time away.

**Inputs** the project's recent commits and uncommitted changes (observed), the last session note, recent agent runs, and the project note.

**Output** a spoken one-line status, then: last verified progress, unresolved issues, relevant files, and one next step. Reported-but-unverified items are labeled.

**Never** invents progress. Thin evidence is stated as thin.
